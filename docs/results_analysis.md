# 复发起冰风险建模：综合结果分析

**数据范围：** 山地自动站2022至2024年记录；10分钟时间步；过去24小时历史窗；未来6小时新起冰风险。

**研究对象：** 当前无覆冰、未处于冷却期且资料完整的站点风险集。

**阅读原则：** 下文只陈述已完成实验直接支持的结论。统计关联、单年优势和探索性结果不表述为稳定的预测增益或因果机制。

**结果收录范围：** 本文件汇总所有已完成实验的设计口径、汇总指标、对照结果、敏感性分析、Bootstrap区间和告警评估。逐时刻预测、逐站点明细、折次与随机种子层面的原始记录仍按实验保存在结果目录中，用于复算和审计；它们不是另一份结论性报告。

**最新重算：** 2026年8月26日完成严格事件网格合同、动态硬预算控制器和公共基准的最终全链重算，并补齐标准DMD、switch-over在线背包、嵌套代价Bootstrap和复杂度审计。主概率模型固定为 `local_weather_hazard`；控制器结构及全部参数只由2022年 pooled OOF选择，2023和2024均为冻结评价。统一主表包含176个运行点，主方法站点簇Bootstrap包含48条预设比较，月度审计包含59,752行，事件匹配记录包含26,136行；理论补充又产生16个标准基线冻结运行点及两组各48条的站点簇Bootstrap。本轮服务器 `experiments/` 目录共55个文件，31个同名文件已替换、24个新文件已加入；完整 `dynamic_hard_budget/` 本地结果树现有83个文件、6个完成标记和711,672,012字节。事件表、三份预测轨迹及2022参数文件均保存SHA-256，理论补充清单中的4个关键哈希与下载文件一致。

## 1. 最终结论

最可信的主结论是：

> 山地起冰可被表示为一个可复发的离散风险过程。本站近期低温、高湿、冷湿暴露、能见度及其时间演变是下一次新起冰风险的主要预测信息。显式复发历史、邻站滞后信号和站点异质性具有解释价值，但尚未显示稳定的跨年增量预测价值。

模型的实际部署价值取决于误报预算。网格锚点修正后，完整窗口队列覆盖2023年的84/116个事件、2024年的116/181个事件；运行现实队列分别覆盖113/116和170/181个事件。固定阈值、滞回和滚动分位数虽然常有较高效用，却存在严重的局部月份超支。新控制器 `uadhbac` 同时满足逐站逐月零超支、未结算容量预留和跨预算嵌套；在预先指定的5小时与10小时档位，其运行现实队列提前量效用相对 `budget_safe` 的四个“年份×预算”比较全部显著提高。由此，当前论文主线已经从“提出动态控制器的动机”推进为“风险预测—提前量收益—动态预算价格—硬容量守卫”的完整实证链。未见站点泛化仍是另一项主要部署瓶颈。

## 3. 哪些信息真正有用

模型归因和消融均表明，主要预测信息来自本站气象历史：平均、最低和最高温度，低温高湿联合暴露，近1小时凝结暴露比例，能见度、降雪、湿度与温度变化。它们描述的是下一次新起冰的风险环境，不是覆冰状态本身。

## 4. 首次与复发的风险结构

统计交互模型支持首次与复发阶段具有不同的风险结构。天气与复发状态交互的联合检验显著，Wald卡方为175.31（5个自由度，P=5.37×10⁻³⁶）。复发阶段中，温度和冷湿暴露的斜率均发生变化；近期7天事件数和前次事件最大厚度也与后续风险正相关。

这些结果说明存在条件关联异质性，但预测收益仅在部分年份出现。因此可以说“首次和复发阶段的风险结构不同”，不能说“按阶段建模已稳定提高跨年预测”。

## 5. 告警治理：效用与预算的取舍

这里必须区分三种量：平均FAH只描述总体资源消耗；逐站逐月硬可行要求每个站点月份的FAH均不超过预算；保留容量可行还把尚未完成随访的未结算告警计入预算。下文只有同时满足后两项时才写作“硬可行”。

### 严格网格修正与双队列评价

旧评价器把事件起点向下取整后又额外后移一个10分钟步长，导致整10分钟事件少取一个预测点。修正后的最后预测点定义为严格早于事件起点的最近10分钟网格点，因此22:30事件和22:28事件的最后预测点都为22:20。运行时和单元测试同时约束：`window_end < onset_time`、事件与窗口末端相差不超过10分钟、36个预测点严格递增且间隔10分钟、窗口跨度350分钟，以及所有有效提前量满足`0 < lead ≤ 6 h`。

### 硬预算与跨预算嵌套的理论保证

令实体—月份为$q$，按升序排列的预算为$B_1<\cdots<B_K$，10分钟离散容量为$C_k=\lfloor 60B_k/10\rfloor$。在时刻$t$和预算$k$下，令$F_{qk}(t)$、$P_{qk}(t)$和$L_{qk}(t)$分别表示已确认误报、尚未结算以及命中后仍锁定的告警格数，并定义占用量$O_{qk}(t)=F_{qk}(t)+P_{qk}(t)+L_{qk}(t)$。

理论保证依赖以下实现假设：

1. 每次接受动作恰好占用一个决策格；容量按整数格向下取整，因而$B_i<B_j$蕴含$C_i\le C_j$。
2. 每个候选动作在发出前先计入未结算容量，即`reserve_pending=true`；右删失动作继续占用其发出月份容量。
3. 结算状态转移不会增加占用量：误报结算仅把一个格从$P$移到$F$；真实事件匹配把$P$释放或等量移到$L$；右删失保持占用。
4. 同一实体内的时间戳按非递减顺序原子处理，且事件仅在`onset_time <= current_time`后进入状态。
5. 跨预算耦合先执行候选继承$d_{k,t}\leftarrow d_{k,t}\lor d_{k-1,t}$，再以联合容量守卫$a_{k,t}=d_{k,t}\land\bigwedge_{j\ge k}[O_{qj}(t)+1\le C_j]$决定动作。
6. 结论不要求危害率校准正确，也不要求事件或预测独立同分布；分布假设只会影响效用，不影响可行性。

**定理1（逐实体逐月硬预算保证）。** 在假设1至4下，若初始$O_{qk}(0)=0$，则对任意预测轨迹、事件序列、右删失模式和时刻$t$，均有$O_{qk}(t)\le C_k$。因此实际FAH及“已确认误报+未结算/锁定容量”的最坏情况占用均不超过$B_k$。

**证明。** 对按时间排序的状态转移作归纳。初始结论显然成立。若当前不接受动作，假设3保证结算、释放或右删失处理后的占用量不增加。若接受动作，容量守卫在写入状态前验证$O_{qk}(t)+1\le C_k$，随后只增加一个未结算格，因此新状态仍不超过$C_k$。跨月告警始终记入发出月份，故月界不会转移或重复使用旧月份容量。归纳得证。移除未结算预留后，接受动作不再受$O+1\le C$约束，该证明失效；对应消融确实出现硬预算违规。

**定理2（跨预算嵌套保证）。** 在假设1至5下，对任意相邻预算$B_k<B_{k+1}$和任意时刻$t$，若$a_{k,t}=1$，则$a_{k+1,t}=1$；因此整段告警集合满足$A(B_1)\subseteq\cdots\subseteq A(B_K)$。

**证明。** 若$a_{k,t}=1$，则$d_{k,t}=1$且所有$j\ge k$的容量检查均为真。候选继承给出$d_{k+1,t}=1$；而$k+1$所需的容量检查集合$\{j:j\ge k+1\}$是前述已通过集合的子集，故$a_{k+1,t}=1$。对所有相邻预算递推即可得到完整嵌套链。该结论逐时刻成立，因此不依赖阈值大小或预测排序。

这两个定理是确定性的安全性结论，不是最优性或遗憾界。特别是，新增的标准对偶镜像下降基线来源于[在线资源分配的Dual Mirror Descent](https://proceedings.mlr.press/v119/balseiro20a.html)，但本项目允许真实事件释放容量并处理右删失，不能直接继承原论文在不可补充资源和随机输入假设下的$O(\sqrt{T})$遗憾界。

### 时间与空间复杂度

设$N$为预测行数，$E$为事件数，$K$为同时评价的预算档位数，$H$为随访窗格数（主实验$H=36$），$M$为实体—月份数。当前批量实现先排序，再计算36步轨迹，并在每个预算下扫描最多$H$个活跃预留，因此一般时间复杂度为$O(N\log N+NH+K(N+E)H)$；在固定$H=36$且$E\le N$时为$O(N\log N+NK)$。若输入已排序，纯在线决策核为$O(NK)$。物化评价的空间复杂度为$O(N(H+K)+MK)$，其中轨迹占$O(NH)$、告警掩码占$O(NK)$、月度审计占$O(MK)$；流式部署只保留一个活动实体的状态与预留队列，额外空间为$O(KH)$。对偶镜像下降和switch-over基线每个“行×预算”仅增加常数次标量更新，不改变渐近复杂度。

服务器一次同时回放4个预算档位的实测结果与该复杂度一致。2023年$N=1,321,566$时，DMD耗时65.14秒、吞吐20,289行/秒，switch-over耗时22.76秒、吞吐58,077行/秒；2024年$N=1,453,371$时分别为72.74秒、19,981行/秒和25.43秒、57,147行/秒。36步危害轨迹的float64数组下界分别为380,611,008和418,570,848字节，四档告警掩码的int8数组下界分别为5,286,264和5,813,484字节。完整理论补充阶段还包含11个2022候选、冻结评价和两组5000次Bootstrap，因此端到端耗时2,735.25秒（45分35秒）；该总耗时不是单步在线决策延迟。

现有报告所称“六类硬守卫基线”专指`budget_safe`、`original_simple`、`uniform_pacing_hard_guard`、`risk_greedy_hard_guard`、`utility_static_hard_guard`和`primal_dual_hard_guard`。固定阈值、滞回和滚动分位数的通用容量包装器是补充诊断，不重复计为算法家族。

| 类别 | 现有覆盖 | 审计结论 | 补充方案 |

| 预算节奏 | `uniform_pacing_hard_guard` | 已覆盖确定性线性节奏；`budget_safe`和`original_simple`为项目特定变体 | 保留，并由标准DMD提供自适应目标消耗对照 |

### 为什么需要嵌套，以及嵌套的效用代价

跨预算嵌套不是为了改善单一预算点的分数，而是为了保证同一风险轨迹在不同服务等级和资源配置下具有一致决策：提高月度资源不应撤销低预算下已触发的告警；月中扩容或降级时已有告警无需重新解释；预算—效用曲线可以用于采购、审计和监管，而不会出现“预算更多、告警反而消失”的配置悖论。旧严格控制器曾出现2024年5小时预算命中率高于10小时预算，说明这一要求具有直接的工程意义。

## 6. 邻站信号与空间泛化

稳定图从560个候选边滞后项中筛得168项，对应62条唯一方向边，但没有转化为稳定的概率、命中率或提前量增益。图边只表示控制本站历史后的预测性滞后关联，不应解释为物理传播因果关系。

留站点组和留地区评估显示明显的未见站点泛化损失。两个此前容易混淆的数值来自不同时间合同：`2022_spatial_holdout`的PR-AUC差为-0.0626，95%区间为[-0.1161, -0.0078]；`2023_spatial_temporal`的PR-AUC差为-0.0521，95%区间为[-0.0964, -0.0175]。两者均表示相对各自全站点参考的下降，不是同一实验的冲突版本。Log Loss也显著变差；留地区与留站点组之间没有稳定差异，说明主要难题是站点未见，而不是现有地区划分。

### 图模型的完整对照

在稳定图的全站点评估中，图模型的排序增益很小且没有跨年一致性。2023年，`stable_sparse_lag_graph`的6小时PR-AUC为0.1126，略高于`local_cloglog_hazard`的0.1105；2024年分别为0.1151和0.1154。相应的2023/2024 Log Loss分别为0.01064/0.01464和0.01060/0.01450。图消融模型在2023/2024的PR-AUC为0.1099/0.1149，未支持邻站图信号的稳定增益。

在固定10小时误报预算、2023年匹配告警比较中，稳定图原模型命中率为80.53%、平均有效提前量3.712小时；移除稳定图后的命中率同为80.53%、平均有效提前量3.853小时。二者命中率差的95%区间为[-5.00, 3.70]个百分点，提前量差为-0.114小时，95%区间[-0.263, 0.028]小时。该受控对照不支持稳定图带来独立的告警收益。

## 7. 告警治理与公共重复事件基准

告警治理流程已完成严格嵌套审计、五类历史基线、硬守卫基线、动态控制器，以及两个公共重复事件基准。公共电商重复购买和美国事故重复发生数据的聚合数据、模型、冻结指标、逐实体月审计和运行清单均保存于 `results/dynamic_hard_budget/public_recurrence_benchmarks/`。

电商基准最终表含32个运行点。`uadhbac_public_Fh_only`在4/8/16/32小时预算下的命中率分别为4.41%、11.74%、21.02%和32.79%，提前量效用分别为0.128、0.356、0.682和1.156小时；四档最大FAH分别为3、5、11和23小时，在线硬预算违规数均为0。无硬守卫的固定阈值、滞回和滚动分位数仍存在局部实体月超支，因此不能仅凭平均FAH宣称预算可行。

美国事故最终表含29个运行点。动态控制器在24/48/96/192小时预算下的命中率为87.11%、95.37%、98.94%和99.93%，最大FAH恰为24、48、96和192小时，在线硬预算违规数均为0。该数据采用每日时间步，提前量为41.59至76.75小时，并且训练标签近乎全阳性；它只用于检查代码和预算机制的可迁移性，不能与覆冰六小时窗口直接比较，也不能作为外部覆冰有效性证据。

这些公共结果用于验证“事件风险、时间顺序、预算控制和严格事件匹配”的工作流可在不同重复事件数据中运行，不是外部覆冰预测验证，也不应外推为气象机制结论。

## 8. 可写与不可写的结论

### 可以作为论文或报告主线

1. 用季节重置复发事件构造风险集的离散时间起冰风险框架。
2. 本站冷湿环境与气象时间演变主导下一次新起冰风险。
3. 首次与复发阶段存在统计上可识别的风险结构异质性。
4. 显式复发历史、邻站滞后和站点异质性未带来稳定跨年增益，这是模型简化的有价值证据。
5. 平均预算满足不等于逐站逐月硬可行；完整窗口与运行现实队列分别提供标准化性能和部署覆盖证据。
6. `uadhbac`通过未结算容量预留、动态预算价格、剩余时间和提前量效用，在2023/2024全部冻结预算档位实现逐站逐月零超支和跨预算零嵌套违规。
7. 相对主要硬可行基线`budget_safe`，`uadhbac`在预先指定的2023/2024、5/10小时四个比较中均显著提高运行现实队列提前量效用；未见站点泛化仍是部署瓶颈。

### 当前证据不支持

1. 完整复发特征模块稳定提高预测精度。
2. 邻站信号稳定提供更早或更准确的预警。
3. 离散时间危害率在概率校准上全面优于普通分类器。
4. 当前模型具备未见站点或未见地区的稳定部署能力。
5. 公共数据基准构成外部覆冰验证或证明气象机制。
6. 嵌套控制器或满足平均FAH的策略已经满足逐站逐月硬预算。
7. 完整窗口队列可以单独代表间隔较短的复发事件；其纳入事件具有更长的前次事件间隔，必须结合运行现实队列解释。
8. 动态控制器在所有预算档位都显著提高命中率；目前严格支持的是四个预设5/10小时比较的提前量效用增益，命中率差并非四项均显著。

## 9. 建议的后续优先级

1. 锁定`local_weather_hazard`和2022 OOF选择得到的`uadhbac`参数，不因2023或2024结果更换策略或调参。
2. 针对完整窗口队列对短间隔复发的选择性，持续报告运行现实队列，并按复发序号、事件间隔、站点和季节分层。
3. 以留站点整簇Bootstrap为固定标准，开发站点域泛化、分层校准或测试时无标签校准。
4. 对公共数据只保留机制可迁移性定位；美国事故在解决近乎全阳性标签和时间尺度问题前不进入主文性能结论。
5. 获取2025年或外部电网数据，以完全未查看数据对概率轨迹、预算可行性和提前量效用进行独立确认。
